# Accounting Policy

Phase 0では、**現物（spot）・JPY建て・レバレッジ1倍・空売りなし**だけを扱う。先物、パーペチュアル、借入、資金調達料、清算は未対応であり、対応するまで入力として拒否する。

## Time and precision

- 内部時刻はUTC。日次境界は00:00:00 UTC。
- 金額、数量、価格、手数料はDecimalで扱い、丸め規則と桁数を設定に固定する。
- event time、receive time、ingest timeを区別し、損益計算の順序はevent timeを基本とする。
- 同一時刻は取引所イベントのsequenceまたは取得順を保存して安定した順序にする。

## Ledger events

最低限、次のイベントを不変ログとして保存する。

- `cash_deposit` / `cash_withdrawal`
- `order_submitted` / `order_rejected` / `order_cancelled`
- `fill`
- `fee`
- `mark`（評価価格）

各イベントは、account、symbol、event time、ingest time、source、数量、価格、手数料、関連order ID、strategy versionを持つ。訂正は元イベントの上書きではなく、訂正イベントとして追加する。

## PnL rules

- 約定時にポジション数量、現金、平均取得原価を更新する。
- 売却時の実現損益は、売却代金から売却数量に対応する平均取得原価と手数料を差し引く。
- 未実現損益は、固定した評価価格から平均取得原価を差し引いて計算する。評価価格の出所と時刻を保存する。
- 手数料は支払資産から差し引き、損益に含める。
- 外部入出金は損益ではなく資本移動として扱う。
- 日次損益は、日初純資産、外部キャッシュフロー、日末純資産から計算する。

## Invariants

検証とペーパー運用の両方で、次を満たさない結果は無効とする。

- 現金とポジションの台帳残高が全イベントの合計と一致する。
- 約定数量、注文数量、取消・残数量の関係が一致する。
- 手数料が二重計上されない。
- 外部入出金を戦略利益として計上しない。
- バックテストとペーパー運用が同じ約定・手数料・評価規則を使う。
